## Εργασία Υπολογιστικού Ηλεκτρομαγνητισμού

Εαρινό εξάμηνο 2025

Υλοποίηση σε Python

- `meshes.py` Περιέχει τις εντολές που δημιουργούν το πλέγμα για κάθε άσκηση.
- `utils.py` Διάφορες συναρτήσεις τόσο άμεσα σχετιζόμενες με FEM, όσο και απλά βοηθητικές για τα διαγράμματα.
- `{a1,a2,b1,b2}.py` Υλοποίηση των ασκήσεων.
Για την εκτέλεση του κώδικα, εγκαταστείστε το εργαλείο `uv` σύμφωναμε με τις οδηγίες [εδώ](https://docs.astral.sh/uv/getting-started/installation/). Κατόπιν τρέξτε τις παρακάτω εντολές μέσα στον φάκελο της εργασίας

```
uv sync
uv run src/a1.py
```

για το ερώτημα Α1. Αντικαταστείστε το `a1` με `a2`, `b1`, `b2` αντίστοιχα για τα υπόλοιπα ερωτήματα.
