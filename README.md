## Εργασία Υπολογιστικού Ηλεκτρομαγνητισμού
Εαρινό εξάμηνο 2025

Υλοποίηση σε Python. 
Για την εκτέλεση του κώδικα, εγκαταστείστε τα dependencies με `pip install -r requirements`. 
- `meshes.py` Περιέχει τις εντολές που δημιουργούν το πλέγμα για κάθε άσκηση. 
- `utils.py` Διάφορες συναρτήσεις τόσο άμεσα σχετιζόμενες με FEM, όσο και απλά βοηθητικές για τα διαγράμματα. 
- `{a1,a2,b1,b2}.py` Υλοποίηση των ασκήσεων.
